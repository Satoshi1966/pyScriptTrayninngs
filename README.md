# Python × HTML はじめてのPyScript

Pythonを使ってブラウザーで動くアプリを作る、初学者向けの学習サンプルです。

HTML・CSS・Pythonコードを1つのHTMLファイルにまとめています。Pythonのインストールや、コマンド入力によるサーバーの起動は不要です。

> **インターネット接続が必要です。**
> PyScript本体とPythonの実行環境をインターネットから読み込みます。完全なオフライン教材ではありません。

## 配布ファイル

| ファイル | 内容 | おすすめの順番 |
| --- | --- | --- |
| [pyscript_template.html](./pyscript_template.html) | 名前を入力して挨拶を表示する基本テンプレート | まずはこちら |
| [pyscript_samples.html](./pyscript_samples.html) | おみくじ・買い物計算・三択クイズのサンプル集 | テンプレートの次に |

各HTMLは、それぞれ単独で実行できます。別のCSSファイルやPythonファイルを用意する必要はありません。

## 用意するもの

- インターネットに接続できるパソコン
- Webブラウザー
- コードを編集するためのテキストエディター（VS Codeなど）

閲覧するだけなら、エディターは不要です。

## ダウンロードして実行する

### まとめてダウンロードする場合

1. このリポジトリのトップページを開きます。
2. **Code → Download ZIP** を選びます。
3. ダウンロードしたZIPファイルを展開します。
4. 展開したフォルダー内の `pyscript_template.html` をダブルクリックします。
5. ブラウザーに「準備できました」と表示されたら、名前を入力して「実行する」を押します。
6. 続いて `pyscript_samples.html` も開いてみましょう。

ZIPファイルの中から直接開かず、展開してから使用してください。

### HTMLを1個だけダウンロードする場合

1. 上の「配布ファイル」から、目的のHTMLファイルを開きます。
2. GitHubのファイル表示画面にある **Download raw file** を使って保存します。
3. 保存したHTMLファイルをダブルクリックします。

GitHubのファイル表示画面では、HTMLのソースコードが表示されます。アプリを動かすには、HTMLファイルをダウンロードしてブラウザーで開いてください。

## サンプルの内容

### 1. 基本テンプレート

**ファイル：`pyscript_template.html`**

名前を入力してボタンを押すと、Pythonが挨拶文を作り、画面に表示します。

このテンプレートでは、次の流れを学べます。

1. HTMLの入力欄に文字を入力する。
2. ボタンを押してPythonの関数を呼び出す。
3. Pythonで文字列を作る。
4. 作った文字列を画面に表示する。

最初は、Pythonコード内の挨拶文を書き換えてみましょう。

```python
message = f"{name}さん、こんにちは！"
message += "\nPythonの学習を始めましょう。"
```

`\n` は改行を表します。

### 2. アプリのサンプル集

**ファイル：`pyscript_samples.html`**

1つの画面に、次の3つのアプリがあります。

| 難易度 | アプリ | できること | 主な学習内容 |
| --- | --- | --- | --- |
| ★☆☆ | 名前入りおみくじ | 名前とランダムな運勢・メッセージを表示 | リスト、乱数、文字列、条件分岐 |
| ★★☆ | 買い物のお会計 | 税抜単価・個数・税率から税込合計を計算 | 整数への変換、四則演算、入力チェック |
| ★★★ | Python三択クイズ | 3問の出題・正誤判定・採点・再挑戦 | 関数、リスト、辞書、変数による進行管理 |

買い物計算では、練習用として税抜合計に対する消費税の1円未満を切り捨てます。

クイズの進行状況や入力内容を保存する機能はありません。ブラウザーを再読み込みすると、クイズの進行や結果はリセットされます。

## コードを変更する

1. ダウンロードしたHTMLファイルを、VS Codeなどのエディターで開きます。
2. 変更する前に、元のファイルをコピーしておきます。
3. コードの文字や数値を少しだけ変更します。
4. ファイルを保存します。
5. ブラウザーでHTMLを開き直すか、再読み込みします。
6. 準備が完了したら、変更が反映されているか確認します。

HTMLファイルの下部にある、次のタグの内側がPythonコードです。

```html
<script type="py">
# ここにPythonコードを記述します。
</script>
```

Pythonの `if` や `def` などの末尾にある `:` と、行頭のインデントに注意してください。

## 通常のPythonとの違い

この教材では、キーボード入力と結果表示にHTMLの部品を使います。

| 処理 | コマンドラインで動くPython | この教材 |
| --- | --- | --- |
| 入力 | `input()` | HTMLの入力欄から `.value` で取得 |
| 表示 | `print()` | 表示先の `.textContent` に文字列を代入 |
| 処理を始めるタイミング | プログラムを起動したとき | ボタンを押したとき |

入力欄の値は文字列です。計算に使う場合は `int()` などで数値に変換します。

```python
# 入力欄から文字列を取得する
name = document.querySelector("#user-input").value

# 結果を画面に表示する
output = document.querySelector("#output")
output.textContent = f"{name}さん、こんにちは！"
```

この例のIDは基本テンプレートのものです。サンプル集では入力欄・表示先ごとに異なるIDを付けています。HTML側の `id` と、Python側の `#` に続く名前を一致させてください。

`print()` の出力は、この教材の結果表示欄に自動では表示されません。また、ブラウザー画面への入力に通常の `input()` をそのまま使うことは想定していません。

## 書き換え課題

### 基本テンプレート

- 挨拶文を変更する。
- 好きな食べ物を入力する欄を追加する。
- 入力内容を使って自己紹介文を表示する。

### おみくじ

- 運勢やメッセージを追加する。
- ラッキーカラーを表示する。
- 時間帯に合った挨拶を表示する。

### 買い物計算

- 合計が3,000円以上ならメッセージを表示する。
- 送料を加えて計算する。
- 支払金額を入力して、お釣りを計算する。

### 三択クイズ

- 問題文と選択肢を変更する。
- 問題を5問に増やす。
- 全問正解したときに特別なメッセージを表示する。

クイズの `answer` は正解の選択肢の位置です。最初は `0`、次は `1`、最後は `2` です。問題を追加するときは、選択肢を3個にしてください。

## うまく動かないとき

| 状況 | 確認すること |
| --- | --- |
| GitHub上にコードだけ表示される | HTMLをダウンロードして、保存したファイルを開いてください。 |
| 「Pythonを準備しています」のまま進まない | インターネット接続を確認し、少し待ってから再読み込みしてください。学校や会社のネットワークで外部スクリプトの読み込みが制限されていないかも確認してください。 |
| ファイルを開くとエディターが起動する | HTMLファイルを右クリックし、「プログラムから開く」などからブラウザーを選んでください。 |
| 変更が反映されない | 保存できているか、編集したファイルとブラウザーで開いたファイルが同じか確認してください。 |
| 編集後にボタンが使えなくなった | Pythonのインデント、`:`、引用符、括弧、HTMLのIDを確認してください。ブラウザーの開発者ツールのコンソールも手がかりになります。 |
| 数値の入力で案内が表示される | 買い物計算では、画面に示された範囲の整数を入力してください。 |
